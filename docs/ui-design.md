# GmScript 本地宏脚本工作台 · 界面设计规范

现有 Swing 模块的对应关系：脚本库←本地文件、中间编辑器←ScriptEditorPanel、右栏←ChatPanel、控制台←ConsolePanel、状态栏←MainFrame 状态标签、钩子←GlobalInputListener。Web 端一一替换，逻辑不动。

## 一、布局与信息层级

基准 1440×900，顶部状态栏固定 40px，其余区域 flex。

| 区域 | 尺寸 | 可调 | 内容 |
|---|---|---|---|
| 顶栏 | 40px 固定 | 否 | 左：脚本名+未保存点；中：运行状态胶囊、钩子胶囊；右：Ollama、设置 |
| 左：脚本库 | 240px | 200–320 | 搜索框、分组、脚本列表 |
| 中：编辑器 | flex，min 480 | 是 | 标签条 32px + 代码区 |
| 右：AI 对话 | 360px | 320–480 | 连接条、消息流、输入区 |
| 底：控制台 | 200px | 120–400，可折叠至 32px | 日志流、清空/过滤 |

层级四级：L1 运行与钩子状态（顶栏胶囊 + 主按钮形态 + 编辑器运行行左侧 2px 绿条）；L2 当前脚本与光标位置；L3 脚本列表、AI 对话；L4 日志细节。滚动只发生在各自面板内部，页面本身不滚。

## 二、暗色令牌

| 类别 | 令牌 | 值 |
|---|---|---|
| 背景 | bg-base / bg-surface / bg-raised / bg-sunken | #1b1d21 / #22252a / #2a2e34 / #16181b |
| 边框 | border-subtle / border-strong / focus-ring | #303439 / #3d434b / #4a7fc1 |
| 主色 | primary / primary-hover / primary-active | #4a7fc1 / #5a8cd2 / #3d6ba8 |
| 语义 | success / warning / danger / info | #52a86a / #d2a24c / #d1615a / #5a8cd2 |
| 文字 | text-1 / text-2 / text-3 / text-disabled | #d6d9de / #9aa1ab / #6e757f / #565c65 |
| 语法 | keyword / string / number / comment / api | #c678dd / #ce9164 / #8cbef0 / #6a9955 / #dec55f |

字号 12 / 13 / 14 / 16 / 20，界面正文 13，代码 14，行高 1.45（代码 1.6）。间距基数 4：4/8/12/16/24/32。圆角：控件 4、卡片与弹窗 6、状态胶囊 999。默认无阴影，靠表面色阶与 1px 边框分层；仅浮层用 `0 8px 24px rgba(0,0,0,.45)`。字体：界面用系统中文黑体，代码/日志/路径用等宽。对比度 #d6d9de 于 #22252a 约 9:1，#9aa1ab 约 5.3:1，满足 WCAG AA。

## 三、组件规格

- 主按钮：高 32，横向内边距 12，主色实填，字重 500，无渐变。运行中变为 danger 实填、文案"停止"。
- 次按钮：透明底 + border-strong，hover 填充 bg-raised，高 28。
- 输入框：单行高 32，AI 输入框多行、最小 36；底色 bg-sunken，边框 border-subtle；focus 态边框变 primary 并加 2px 主色 25% 透明描边。占位文字用 text-3。
- 列表项：高 36，左内边距 8；hover #282c32，选中 #2f343b 且左侧 2px primary 竖条；右侧 12px text-3 显示修改时间。
- 消息气泡：用户靠右、底色 #2d3a4e；助手靠左、底色 #2a2e34；圆角 6，最大宽度 88%，间距 12；气泡上方 12px text-3 标注"你 / 助手"。代码块底色 bg-sunken，带复制按钮。
- 状态指示灯：8px 圆点 + 12px 文字，绿=运行中、灰=已停止、黄=待处理、红=错误。同一时刻全屏只允许一个"绿"。
- 日志行：等宽 13/1.6，时间戳 text-3 固定 68px，级别词着色即可，禁止整行铺色；错误行另加左侧 2px danger 竖条。
- 空状态：居中，14px text-1 一句标题 + 13px text-2 一句说明 + 一个次按钮。不用插画、不用 emoji。

## 四、关键状态

| 状态 | 视觉表达 |
|---|---|
| 脚本运行中 | 顶栏绿点胶囊"运行中 00:12:34"（走动计时）；主按钮转红"停止"；编辑器正在执行的语句左侧 2px 绿条；控制台标题条左侧绿点 |
| 已停止 | 灰点胶囊"已停止 · 上次运行 12s"；主按钮恢复主色"运行 F5"；运行行高亮清除 |
| 钩子未启用 | 顶栏黄点胶囊"钩子未启用"，点击直达启用入口；控制台首行黄色提示写明原因（如"需要管理员权限"） |
| Ollama 未连接 | AI 面板顶部通栏黄条"Ollama 未连接 127.0.0.1:11434" + 次按钮"重试""设置"；输入框可输入，发送按钮置灰并提示原因 |
| 编译报错 | 顶栏红点胶囊"编译失败 1 处"；控制台红字 + 左竖条；编辑器行号槽红点，点击定位；全程不弹窗打断 |

状态变化只做 150ms 颜色过渡，不闪烁、不弹跳、不自动弹出面板。

## 五、中文文案规范

短句、动词开头，一句一件事。按钮 2–4 字：运行、停止、重试、启用钩子、清空日志。错误必须给原因和下一步："未找到 Ollama，请确认服务已启动，或在设置里修改地址"。占位符写示例不写空话："输入想要脚本做的事，例如：循环按 F 键 5 秒"。不用感叹号、不用 emoji、不用"智能/赋能/一键搞定/让我们/亲"；数字、路径、坐标一律等宽体。

## 六、明确避免

渐变与玻璃拟态；大于 8px 的圆角堆砌；无来由的阴影与悬浮位移；emoji 装饰；整行彩色日志；同时出现多个脉冲动画；第二套品牌字体；"AI 味"套话与自我表扬式副标题。
