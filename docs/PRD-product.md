# PRD：GmScript 重构（Java 本地服务 + Web 前端）

v0.1｜Alex｜2026-10-27｜基线 4085 行 Swing 单体（fe0178c）

**红线**：浏览器只做控制面；全局钩子、键鼠注入、LuaJ 执行必须同进程。前端只调 loopback API，不直接注入。
**北极星**：5 分钟内「开页面 → 游戏内热键生效」；跑飞后 3 秒内停住并释放按键。

## 1 目标用户与痛点

**U1 自用玩家（主，不写代码）**
- AI 输出整段覆盖编辑器：`setScript()` 后 `discardAllEdits`，手改内容与撤销栈一起丢。
- 钩子只在 `runScript()` 里才 `start()`：不跑脚本，热键就是死的。
- 配置只存一个 `lastScript` 字符串，换脚本靠文件对话框挑 `.lua`。
- 默认 `dashscope/qwen-plus`、baseUrl 空 → 回落 api.openai.com，本机 Ollama 闲置。

**U2 折腾型脚本作者**
- 知识库只读（classpath 内置 11 条），自有模板散在磁盘。
- 日志只进 Swing 组件（限 5000 行），不落盘、不可导出。
- `EventDispatcher` 只挂一个引擎，多脚本并存不可能。

## 2 三条端到端旅程

**J1 首次生成并跑通**
1. 开 `127.0.0.1:<port>/?token=…` → 脚本库空态，状态条「服务在线·钩子未启用」。
2. 右上「AI 助手」输入「按住右键自动连点，150ms」→ 流式输出 + 思考折叠。
3. 完成弹 diff 预览（左当前／右 AI）→ 选「存为新脚本」→ 命名 → 库中新增，状态「未绑定热键」。
4. 点「绑定热键」→ 捕获框请按键 → 按 F8 → 状态条「钩子已启用·1 脚本已绑定」。
5. 游戏内按 F8 → 页面日志滚「F8→启动 自动连点器｜第 3 次点击」；再按 F8 → 「已停止·按键已释放」。

**J2 取现成脚本改造**
1. 顶栏「知识库」→ 按 game/tag 分组，右侧详情含说明与源码。
2. 「复制到我的脚本库」→ 生成 `(副本)` 且标签继承 → 点条目进编辑器。
3. `Sleep(80)` 改 `150` → Ctrl+S，旧版进该脚本历史；点「校验」→ LuaJ 只编译，错误按行号标红。
4. 点「运行」→ 日志逐行推送；游戏内按 F8 生效且日志出现「热键触发」标记，证明注入在 Java 侧。

**J3 跑飞与排障**
1. 死循环 → 按 `Ctrl+Shift+F12` → 日志「已请求停止｜已释放按键 F8、鼠标左键｜鼠标速度已还原」。
2. 3 秒未停 → 红色横幅 +「强制终止引擎」+ 最近 200 行日志。
3. 「日志」页按脚本/时间过滤出时间轴并导出 `.log`；问题脚本标「禁用」，改跑库里另一个。

## 3 功能分级

| 级别 | 内容 |
|---|---|
| MVP | ①本地服务 HTTP+SSE，仅绑 127.0.0.1，token 鉴权 ②脚本库：多脚本 CRUD、标签、启停、`.lua` 导入导出、保存留版本 ③热键：每脚本一键、捕获录入、钩子常驻、应急键可配 ④执行日志：状态机 + SSE 实时流 + 落盘 ⑤编辑器：Lua 高亮、服务端编译校验返回行列号 ⑥AI：默认 Ollama（coder:7b 生成 / qwen3:8b 通用，可切云端）、流式、diff 预览 + API 白名单校验 ⑦知识库只读：11 条、关键词检索、复制到库、勾选注入上下文 |
| 二期 | 知识库可编辑 + nomic-embed-text 语义检索；宏录制生成 Lua；多脚本并存与同键互斥；日志查询回放；脚本市场（导入链接、下载计数、来源风险提示）；模型管理 |
| 三期 | 可视化块编辑器；版本 diff 与云同步；插件 API + 社区审核；图像/条件触发；局域网受控部署 |

## 4 MVP 验收

1. 仅监听 127.0.0.1（`netstat` 无 0.0.0.0）；无/错 token 一律 401。
2. 库 ≥10 脚本，重启全保留；导出再导入逐字节一致。
3. 无脚本运行时按键 200ms 内触发对应脚本；重启自动生效；改应急键后旧键立即失效。
4. 停止后线程 1 秒内退出，已按键鼠全部释放（按住 W 时停止 → `IsKeyPressed("w")`=false），鼠标速度还原；日志延迟 <300ms。
5. 存含错脚本返回 400 + `{line,column,message}` 并标红该行；合法返回 200。
6. 无云密钥时生成走 `localhost:11434` 且产出可编译 `OnEvent`；非法 API 提示「含未支持函数：xxx」并禁用「应用」；取消 diff 后内容与撤销栈不变。
7. 搜「压枪」命中；勾 2 条后日志显示上下文已注入；复制到库后新 id 唯一且不影响原条目。

## 5 不做什么

- 前端不做钩子/注入（红线）；MVP 不做 WebSocket。
- 不做 macOS/Linux：SendInput 仅 Windows，启动即提示。
- 不读写游戏内存、不绕反作弊、不做 DMA/驱动注入，市场内此类脚本下架。
- 不做账号、云同步、协作、付费；不暴露局域网/公网。
- MVP 不做并发多脚本、宏录制、块编辑、市场、自动更新、安装器。
- 不保留旧 Swing 界面，避免双维护。

## 6 风险

| 风险 | 缓解 |
|---|---|
| 本地 API 遭 CSRF/DNS rebinding，被网页远程触发注入 | 仅 loopback；写操作要 `X-GmScript-Token` 自定义头 + 校验 Origin；敏感操作二次确认 |
| 钩子常驻致延迟或被游戏屏蔽 | 仅有绑定脚本时注册；回调只入队；可暂停钩子 + 延迟自检 |
| LuaJ 非线程安全、事件仅在 `Sleep()` 派发，长阻塞脚本堆事件 | 单脚本线程 + 有界队列（溢出丢弃告警），引导事件驱动写法 |
| 应急停止不释放已按键 → 卡键 | `InputSimulator` 加 `releaseAll()` 并纳入停止路径（验收 4） |
| AI 幻觉 API 或覆盖用户代码 | 白名单 + 编译校验 + diff 三重门，不过则禁用「应用」 |
| 残留 Swing 依赖、`System.out` 打印完整请求响应、密钥明文存 `~/.gmscpt/config.json` | 核心层去 UI 化；结构化脱敏日志；密钥独立文件、环境变量优先 |
| 范围过大重演「粗糙且 bug 多」 | 只交付 MVP 闭环，二期需 MVP 达标后评审 |
